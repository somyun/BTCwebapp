# 호포기지 CAD 지도 적용 기술 및 기능

이 문서는 현재 웹앱에 실제 적용되어 동작하는 기술과 기능만 정리한다.

## 1. CAD 도면 데이터 처리

- DWG 도면을 개발 단계에서 웹용 데이터로 사전 변환하며, 사용자는 도면을 업로드하지 않는다.
- 도면을 `manifest.json`과 레이어별 JSON 파일로 분리해 필요한 레이어만 불러온다.
- 도형은 경로, 점, 문자 데이터로 구분해 저장한다.
- 5개 기준점을 이용한 2차원 유사변환 최소제곱법으로 도면 좌표를 `EPSG:4326` 경위도에 정합했다.
- 현재 정합 결과는 평균제곱근오차 약 1.67m, 최대 잔차 약 2.57m이다.

## 2. 지도 및 도면 렌더링

- 카카오 지도 JavaScript SDK를 베이스 지도로 사용한다.
- 일반지도와 위성지도를 하나의 토글 버튼으로 전환한다.
- CAD 도형과 문자를 SVG 벡터 레이어로 표시한다.
- 선에는 비확대 선 속성을 적용해 확대 시에도 선명도를 유지한다.
- 지도 좌표 투영값으로 SVG의 위치와 크기를 다시 계산해 지도 이동 및 확대·축소에 동기화한다.
- 레이어 데이터는 최초 요청 후 메모리에 캐시한다.

## 3. 모바일 조작 및 화면 방향 대응

- 카카오 지도 기본 핀치 확대·축소 중 CAD 레이어도 실시간으로 따라간다.
- 가로모드에서는 핀치 중심점과 이동량을 회전된 지도 좌표계로 변환해 지도와 도면의 중심을 일치시킨다.
- 화면 방향을 감지해 북쪽이 기기의 실제 상단을 향하도록 지도를 자동 회전한다.
- 가로모드 드래그 방향을 회전각에 맞게 변환한다.
- 도면 문자는 지도 회전의 반대 방향으로 보정해 항상 읽기 쉬운 방향을 유지한다.
- 화면 방향 변경 후 카카오 지도 재배치와 중심 복원을 수행해 지도 타일 누락을 방지한다.

## 4. 확대 및 문자 표시

- 카카오 지도의 최대 확대 단계 이후 `추가확대`로 2배 벡터 확대를 제공한다.
- 추가확대 시 문자 크기에 가독성 보정값을 적용한다.
- 문자표시는 기본으로 활성화된다.

## 5. 레이어 표시 기능

- 표시설정에서 레이어별 표시 여부, 전체 선택, 전체 해제 및 핵심 레이어 선택을 지원한다.
- 도면 투명도를 조절할 수 있다.
- 기본 레이어에 기존 핵심 레이어와 `TEAM_A`~`TEAM_D`를 포함한다.
- 설정 창 바깥을 누르면 레이어 설정 창이 닫힌다.
- 가로모드에서는 설정 창이 사용 가능한 화면 높이를 채우며 마지막 레이어까지 스크롤할 수 있다.

## 6. 현재 위치 기능

- 브라우저 위치 권한을 사용해 현재 위치로 지도를 이동한다.
- 현재 위치 마커와 위치 정확도 범위를 함께 표시한다.
- 위치 확인 중·완료·오류 상태를 화면에 안내한다.

## 7. 도면 문자 검색

- 전체 CAD 레이어의 문자 데이터를 검색하며 정확 일치, 앞부분 일치, 부분 일치 순으로 결과를 정렬한다.
- 여러 결과를 문자명과 레이어명으로 목록 표시한다.
- 검색 결과를 선택하면 해당 위치로 지도를 이동하고 카카오 지도 핀을 표시한다.
- 돋보기 버튼으로 상단 버튼 영역을 검색창으로 전환하며 `<` 버튼으로 기존 버튼 영역으로 복귀한다.
- 검색 인덱스와 레이어 데이터는 최초 요청 후 메모리에 캐시한다.

## 8. 사용자 인증

- 부산교통공사 `@humetro.busan.kr` 계정만 지도 화면 인증을 요청할 수 있다.
- 사용자는 이메일 아이디만 입력하며 도메인은 자동으로 결합된다.
- Google Apps Script가 6자리 이메일 인증코드를 발송·검증한다.
- 검증 후 Firebase 사용자 지정 토큰으로 로그인한다.
- Firebase 로컬 인증 지속성을 사용해 같은 브라우저 또는 PWA에서는 로그인을 유지한다.

## 9. 웹앱 및 배포

- GitHub Pages에서 정적 웹앱으로 배포한다.
- 웹 앱 매니페스트와 앱 아이콘을 제공해 PWA 설치를 지원한다.
- 반응형 UI로 PC와 모바일의 세로·가로 화면을 지원한다.
- 정적 자원 버전 값을 사용해 배포 후 브라우저 캐시를 갱신한다.
- 지도 진입 버튼은 메인페이지의 `호포기지 도면보기`로 제공한다.

## 10. 검증

- 지도 확대, 핀치 중심, 화면 회전, 드래그 방향, 레이어 UI 및 이메일 인증을 자동 테스트한다.
- 지도 문자 검색과 검색 결과 이동·핀 표시도 자동 검사 범위에 포함한다.
